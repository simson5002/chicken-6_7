### Project Description

**Chicken 6 7** is a completely unnecessary food-delivery experience where you don't choose your food first.

Instead, you choose **your delivery person**.

Swipe through delivery-person profiles, check their ratings, location, and delivery stats, and swipe right on the person you trust to bring your precious food to you. Because apparently choosing what to eat wasn't complicated enough.

### The Problem (that doesn't exist)

Traditional food-delivery applications make one terrible assumption:

**That customers actually care about choosing food and restaurants.**

They completely ignore the most important part of the delivery experience:

> **Who is going to bring my food?**

You don't know whether your delivery person is punctual, trustworthy, compatible with your snack requirements, or capable of surviving your increasingly desperate "bro where are you?" messages.

Chicken 6 7 solves this extremely serious problem that absolutely nobody asked us to solve.

### The Solution (that nobody asked for)

Chicken 6 7 turns food delivery into a **Tinder/Bumble-style matching experience**.

Instead of browsing restaurants, users browse delivery-person profiles.

Each profile can contain:

* Profile photo
* Delivery rating
* Successful deliveries
* Location
* Short description
* Other completely unnecessary compatibility information

Swipe **left** to reject.

Swipe **right** to choose.

If the chemistry is right, you get a match.

Then, and only then, may you proceed to the important business of actually getting your food.

For Software:

# Installation

Clone the repository:

```bash
git clone https://github.com/[your-username]/chicken-6-7.git
cd chicken-6-7
```

Install dependencies:

```bash
npm install
```

# Run

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

To create a production build:

```bash
npm run build
```
